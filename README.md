# TextQuest – File-Based Keyword Search Engine in C

## Description
TextQuest is a command-line application written in C that allows users to store lines of text in a file and search for specific keywords.  
The program displays all matching lines along with the total number of matches found.

This project demonstrates the use of file handling, string processing, and modular programming in C.

---

## Features
- Add text lines to a file
- View all stored text
- Search for a keyword in the file
- Display matching lines and match count

---

## Concepts Used
- File Handling (`fopen`, `fgets`, `fprintf`)
- String Functions (`strstr`)
- Structures
- Functions
- Loops and Conditional Statements
